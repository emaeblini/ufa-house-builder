# Данные для анализа рынка частных домов

Данные предназначены для анализа рынка частных домов в Уфе и Уфимском районе. Они используются для обоснования разработки сайта строительной компании.

## Файлы

- `housing_market.csv` — объёмы строительства жилья в Башкортостане за 2020–2025 годы.
- `search_demand.csv` — помесячный поисковый интерес к покупке и строительству домов за 2024–2026 годы.
- `buyer_preferences.csv` — предпочтения покупателей загородной недвижимости.
- `search_channels.csv` — способы поиска загородной недвижимости.
- `population_ufa.csv` — население Уфы и Уфимского района.
- `audience_scenarios.csv` — оценка потенциальной аудитории по трём сценариям.

## Примечание

Статистика строительства, населения и результаты опросов взяты из открытых источников. Поисковый спрос смоделирован. Оценка аудитории также основана на условных предположениях.
